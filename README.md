## ◈ About The Project

**Sharvil's Portfolio** is my personal website, designed to present my technical journey, skills, projects, and achievements through a modern and visually engaging digital experience.

The website acts as a central place where visitors can explore my work, understand my technical interests, and connect with me.

The design follows a futuristic visual direction with a dark aesthetic, red accents, interactive elements, and 3D-inspired presentation.

## ◈ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/sharvilpawar123-source/sharvil-portfolio.git
```

### 2. Navigate to the project

```bash
cd sharvil-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
